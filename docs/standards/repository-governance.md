# Repository Governance

> **Status:** Draft foundation standard

GitHub is the initial planning and source-control system for InfrastructureIntent.

## Planning model

- **GitHub Projects**: cross-repository planning and current delivery status.
- **Milestones**: meaningful delivery or release boundaries.
- **Issues**: planned units of work.
- **Pull requests**: implementation and review evidence.
- **Iteration logs**: local execution narrative and validation evidence.
- **Documentation repository**: canonical architecture, standards, and cross-repository summaries.

Repository protection, required checks, release rules, and project-field conventions will be defined as the repository template and first implementation repositories are bootstrapped.
