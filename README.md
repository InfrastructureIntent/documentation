# InfrastructureIntent Documentation

This repository is the canonical public documentation source for the InfrastructureIntent project.

InfrastructureIntent is an infrastructure intent compilation ecosystem. The project separates declarative Intent, infrastructure-domain semantics, a deterministic Resource Graph, Integration-owned Backends, and Target-specific validation and emission.

## Repository role

This repository owns cross-project documentation, including architecture and ADRs, terminology, worked pressure-test scenarios, engineering standards, governance/licensing policy, and future cross-repository weekly progress and architecture-drift reporting.

Repository-local implementation notes and daily iteration logs belong with the repository that owns the implementation. Organization-wide architecture and standards belong here.

## Architecture status

The architecture is currently in active design and foundation work. ADRs are **Proposed** unless explicitly marked otherwise. Concrete pressure tests and implementation evidence are used to promote or revise decisions.

## Contributions

External pull-request contributions are not yet accepted while the contributor agreement and inbound IP terms are finalized. Issues and discussion may be used for feedback in the meantime. See [CONTRIBUTING.md](CONTRIBUTING.md).
