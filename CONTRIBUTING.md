# Contributing to InfrastructureIntent

InfrastructureIntent is currently in foundation work.

External pull-request contributions are not yet accepted while the project finalizes its contributor agreement and inbound intellectual-property terms.

You are welcome to open issues for feedback, design discussion, defects, interoperability concerns, or proposed extensions.

Do not submit code or documentation contributions intended for merge until the contributor agreement is published and the repository explicitly announces that external contributions are open.

The expected future model includes a contributor agreement reviewed before public contribution intake, explicit acknowledgement of the applicable repository license, architecture/conformance requirements for public contracts and extensions, and normal GitHub issue/pull-request workflows.
